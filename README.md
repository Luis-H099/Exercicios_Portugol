# Exercícios de Portugol

Aqui estão alguns exercícios e atividades que fiz para praticar lógica de programação usando Portugol.

Os exercícios envolvem:

- Variáveis e entrada de dados;
- Operações matemáticas;
- Condições;
- Estruturas de repetição;
- Cálculos e contadores.

Os arquivos podem ser abertos e executados pelo Visualg.
