# 📗 Exercícios de Portugol

Repositório com atividades e algoritmos desenvolvidos em **Portugol** durante meus estudos de lógica de programação.

## 🎯 Objetivo

Praticar os fundamentos da programação, desenvolver o raciocínio lógico e aprender a transformar problemas em algoritmos organizados e compreensíveis.

## 📚 Conteúdos praticados

Os exercícios disponíveis abordam:

- Declaração de variáveis e tipos de dados;
- Entrada e saída de informações;
- Operações matemáticas;
- Cálculo de áreas, médias e descontos;
- Estruturas condicionais (`se`, `senao`);
- Estruturas de repetição (`enquanto`);
- Contadores e verificações de divisibilidade.

## 🧩 Atividades presentes

Entre os algoritmos registrados estão:

- Apresentação de informações do usuário;
- Cálculo de valor de compra com desconto;
- Cálculo da área de um terreno;
- Cálculo de média e situação do aluno;
- Contagem regressiva;
- Identificação de números divisíveis por 3.

## ▶️ Como executar

Os arquivos possuem extensão `.ALG` e podem ser abertos em um ambiente compatível com Portugol, como o **Visualg**.

1. Baixe ou clone este repositório.
2. Abra o Visualg ou outro interpretador compatível.
3. Abra o arquivo da atividade desejada.
4. Execute o algoritmo para testar seu funcionamento.

## 📁 Organização

Cada atividade é mantida em seu próprio arquivo, com o objetivo de facilitar a leitura, a execução e a consulta dos exercícios.

## 🚀 Evolução

Este repositório acompanha meu aprendizado em lógica de programação. Novos algoritmos serão adicionados conforme eu avançar nos estudos.
